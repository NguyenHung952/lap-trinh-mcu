# Alarm Clock + DS3231

Ứng dụng đồng hồ báo thức trên STM32 kết hợp RTC DS3231, LCD, Button, Timer, LED và Buzzer.

## Chức năng

- Hiển thị thời gian thực.
- Cài đặt và bật/tắt báo thức.
- Đọc thời gian từ DS3231.
- Hiển thị nhiệt độ nếu cấu hình hỗ trợ.
- Hiển thị trên LCD 16x2.
- Báo thức bằng LED và Buzzer.
