# External Interrupt (EXTI)

Thực hành cấu hình và xử lý External Interrupt / EXTI trên STM32 bằng STM32CubeMX và STM32 HAL.

## Nội dung

- GPIO ở chế độ External Interrupt.
- Rising Edge / Falling Edge.
- Pending bit và Interrupt Priority.
- HAL callback cho interrupt.
- SysTick và HAL_GetTick().
- Luồng xử lý từ interrupt đến application.

## Công cụ

- STM32CubeMX
- STM32CubeIDE
- STM32 HAL
- ST-Link
