# 🧩 STM32 Projects

Mỗi thư mục là một project tương đối độc lập và có README.md riêng.

## Quy ước
- Tên thư mục: tiếng Anh, chữ thường, dùng dấu -.
- Không commit Debug/, Release/ hoặc file build sinh tự động.
- Giữ .ioc, .project, .cproject, Core/, Drivers/ và linker script khi chúng thuộc project.
- Ưu tiên tách Driver, Application và logic xử lý theo module.
