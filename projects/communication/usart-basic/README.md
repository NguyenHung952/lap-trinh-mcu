# USART1 Communication

Project thực hành giao tiếp USART1 trên STM32 bằng STM32 HAL.

## Chức năng

- Khởi tạo USART1.
- Gửi thông báo khi khởi động.
- Gửi Counter định kỳ.
- Định dạng chuỗi bằng snprintf().
- Truyền dữ liệu đến Serial Terminal.

## Hướng phát triển

- UART Receive
- UART Interrupt
- UART DMA
- CLI
- Trao đổi dữ liệu với PC
