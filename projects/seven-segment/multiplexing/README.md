# Seven-Segment Multiplexing

Điều khiển LED 7 đoạn bằng 74HC595 và kỹ thuật Multiplexing.

## Nội dung

- GPIO Bit-Banging.
- 74HC595.
- Lookup Table.
- Quét nhiều LED.
- Timer Polling.
- Xử lý dữ liệu bằng dịch bit và AND.
- Driver module hóa.

## Công cụ

- ARM KIT
- STM32
- STM32CubeMX
- STM32CubeIDE
