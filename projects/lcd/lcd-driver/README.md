# LCD Driver HD44780

Xây dựng Driver cho LCD 16x2 HD44780, giao tiếp 4-bit với STM32.

## Nội dung

- RS, RW và Enable.
- 4-bit data bus.
- Gửi command / data.
- Quy trình khởi tạo LCD.
- Public API và Private Function.
- Tách Driver khỏi Application.

## Công cụ

- STM32CubeMX
- STM32CubeIDE
- STM32 HAL
